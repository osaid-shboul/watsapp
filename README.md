# Hawalat App

تطبيق لإدارة الحوالات ومحادثات واتساب، مع تكامل Airtable وإضافة للمتصفح.

## التشغيل المحلي

1. ثبّت Node.js ثم نفّذ `npm ci`.
2. انسخ `.env.example` إلى `.env.local` واملأ القيم الخاصة بك.
3. شغّل `npm run dev` وافتح `http://localhost:3010`.

ملفات الجلسات والمحادثات والوسائط وبيانات التطبيق تُنشأ محليًا وتبقى خارج Git. لا تضع رموز API أو بيانات العملاء في الكود أو في ملفات ترفعها إلى المستودع.

إضافة المتصفح موجودة في `chrome-extension/`، ويمكن تنزيل نسختها المضغوطة من التطبيق.
